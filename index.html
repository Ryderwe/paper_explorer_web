Paper·Explorer

一个小工具：粘贴一篇论文，立刻看到它引用了谁、又被谁引用。

它解决什么

写论文、读论文时，总要沿着引文网络上下追溯。这里把 Semantic Scholar 的数据整理成两栏：一栏是你这篇论文引用的文献（References），另一栏是后来引用它的工作（Citations）。每条都直接附上 arXiv、PDF、DOI、Google Scholar 的跳转。

怎么用

  1. 在搜索框粘贴下面任意一种内容：

2510.18936  ·  arxiv.org/abs/2510.18936  ·  10.3866/PKU.WHXB201112303  ·  或者直接输入论文标题。

小提示

Semantic Scholar 匿名接口大约 1 次 / 秒。频繁查询被限流时，在顶部填入自己的 API Key（仅存你本地浏览器）。
